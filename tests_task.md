# Задание - реализация интеграционных тестов

Необходимо написать интеграционные тесты для обработчиков запроса из функции
func (h *UsersHandler) HandleStart(res http.ResponseWriter, req *http.Request)
в файле internal/server/users.go

При написании интеграционных тестов для запросов должны быть использованы заглушки:
- для запросов к внешним системам по REST API (если такие запросы имеются)
- для взаимодействия с БД Postgresql (желательно использовать библиотеку "github.com/pashagolub/pgxmock/v5")

Не создавать заглушки для сервисов и репозиториев, которые реализованы в этом проекте, вместо этого использовать существующие реализации.

Тесты должны покрывать основные ветвления логики.

Формат тестов должен быть примерно таким:

```golang
var testsList = []struct {
    name string
    when when
    want want
}{
    {
        name: "...",
        when: {
            // описание условий теста
        },
        want: {
            // описание ожидаемого результата
        }
    }
}

func TestFunctionName(t *testing.T) {
	for _, test := range testsList {
        t.Run(test.name, func(t *testing.T) { 
            // setup
            ...
            // when
            ...
            // проверка ожидаемого результата
            ...
        }
    }
}
```
